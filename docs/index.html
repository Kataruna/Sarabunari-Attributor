Attributor

Inspector attributes for Unity 6: nested groups with columns, buttons where you declare them, and a few field helpers.

Install

Package Manager → + → Install package from git URL, then paste:

https://github.com/Kataruna/Sarabunari-Attributor.git

Add #v0.6.0 to the end to pin a version. Then in your scripts:

using Sarabunari.Attributor;

Layout

[Group("Title", columns)]

An always-open box with a title. Members with the same title share one box. The number sets how many columns it has; leave it out for one.

Code
[Group("Stats")] public int health = 100;
[Group("Stats")] public float speed = 4.5f;

[Group("Colors", 2)] public Color primary;
[Group("Colors", 2)] public Color secondary;
Inspector
Stats
Health100
Speed4.5
Colors
Primary
Secondary

[Group(columns)]

A row with no box or title. Members declared one after another share the row. Handy for lining up buttons.

Code
[Group(3)] [Button] void Spawn() { }
[Group(3)] [Button] void Reset() { }
[Group(3)] [Button] void Clear() { }
Inspector
Spawn
Reset
Clear

[Fold("Title", columns)]

Like Group, but it can be collapsed. Whether it's open is remembered for the editor session.

Code
[Fold("Audio")] public AudioClip jump;
[Fold("Audio")] public AudioClip land;
[Fold("Debug")] public bool drawGizmos;
Inspector

Nesting

Use / in a title to nest boxes, or stack Fold and Group attributes. They nest left to right.

Code
[Fold("Corners")] [Group("Outer", 2)]
[SerializeField] Transform topLeft, topRight,
                           bottomLeft, bottomRight;

[Group("Border/Inner", 2)]
[SerializeField] float left, right;

Buttons and read-only values

[Button] · [Button("Label", mode)] · [Button("Label", args...)]

Draws a method as a button, in the place it's declared. Values after the label are passed to the method's parameters, and stacking several Buttons on one method gives one button each. Parameters left out need a default value; a value of the wrong type disables the button with the reason in its tooltip. Clicking is recorded for Undo and marks the scene dirty. EButtonEnableMode.Playmode makes it clickable only in Play mode; Editor only outside it.

Code
[Button]
void Randomize() { /* ... */ }

[Button("Fire!", EButtonEnableMode.Playmode)]
void Fire(int count = 1) { /* ... */ }

[Button("Add 1 Hour", 1), Button("Add 2 Hours", 2)]
public void AddHours(int amount) { /* ... */ }
Inspector (edit mode)
Randomize
Fire!
Add 1 Hour
Add 2 Hours

[Show]

Makes a private or non-serialized field readable in the inspector, not editable, refreshed while the inspector is open.

Code
[Show] private float currentSpeed;
[Show] private GameObject target;
Inspector

Field helpers

[ReadOnly]

Locks a public or serialized field so it still shows in the inspector but can't be edited ([Locked] is also available as an alias).

Code
[ReadOnly] public string id = "enemy-07";
Inspector
Idenemy-07

[Line] · [Separator]

A separator line above the field. [Separator] is an alias.

Code
public int lives = 3;
[Line]
public int score;
Inspector
Lives3
Score0

[EnableIf("name")] · [DisableIf("name")]

EnableIf makes the field editable only while a bool field, property or method is true. DisableIf greys it out while it's true.

Code
public bool useCamera;

[EnableIf("useCamera")]
public Camera cam;

[DisableIf("IsLocked")]
public float zoom = 1;
bool IsLocked() => useCamera;
Inspector (useCamera off)
Use Camera
CamNone (Camera)
Zoom1

[OnChange("Method")]

Calls a method with no parameters after the field's value changes while its inspector is open. That includes edits, Undo, and code that writes the field in Play mode.

Code
[OnChange("ApplyColor")]
public Color tint = Color.white;

void ApplyColor() =>
    GetComponent<Renderer>().sharedMaterial.color = tint;
Inspector
Tint
Editing Tint calls ApplyColor()

[Expandable]

For a ScriptableObject reference: adds an inline expand arrow on the field row so you can inspect and edit the asset's fields right where it is declared.

Code
[Expandable] public WeaponConfig weapon;

[SceneName]

On a string: pick a scene from the enabled scenes in Build Settings. A scene that's no longer listed shows as (missing).

Code
[SceneName] public string nextLevel;
Inspector
Next LevelLevel02

[MinMaxSlider(min, max)]

On a Vector2: a two-handle slider with number boxes. x is the low end and y the high end; typed values are kept within the limits and in order.

Code
[MinMaxSlider(0, 10)]
public Vector2 spawnDelay = new(2, 6);
Inspector
Spawn Delay26

[Required] · [Required("Message")]

On an object reference: shows an error box under the field while it's empty.

Code
[Required("Assign the canvas")]
public CanvasGroup canvas;
Inspector
CanvasNone (Canvas Group)
Assign the canvas

[SelfAssign]

On a component reference: adds an inline Self button that calls GetComponent on the same GameObject and assigns it. Shows a red error label and logs a warning if the component is missing.

Code
[SelfAssign]
public Rigidbody rb;
Inspector
RbNone (Rigidbody)Self

[GetChild] · [GetChild(recursive, includeInactive)]

On a List<T> or T[] of components: adds a Get Child button that populates the list or array with matching components from child GameObjects (excluding the parent itself). Shows a red error label and logs a warning if no child has that component.

Code
[GetChild]
public List<Collider> hitboxes;
Inspector
▸ Hitboxes2Get Child

[Preview]

On a texture, sprite, prefab or other asset reference: shows its thumbnail under the field. Nothing is shown while the field is empty or the object has no preview (e.g. a scene object).

Code
[Preview]
public Sprite icon;
Inspector
Icon◉ Coin (Sprite)

[Gallery] · [Gallery(columns)]

On a List<T> or T[] of asset references: shows a grid of thumbnails under the list, one square cell per element. The number sets columns (default 4).

Code
[Gallery(3)]
public List<Sprite> icons;
Inspector
▸ Icons5

[DropZone]

On a List<T> or T[] of object references: shows a drop area under the list's name, above its elements. Objects dropped on it are added to the end. A dropped GameObject adds its matching component, and objects of the wrong type are skipped.

Code
[DropZone]
public List<Sprite> icons;
Inspector
▾ Icons3
Drop Sprite here
Element 0◉ Coin (Sprite)

Notes

  • ReadOnly, EnableIf, DisableIf, OnChange, GetChild, Gallery, DropZone, Group, Fold, Button and Show work on members of a MonoBehaviour or ScriptableObject, not inside nested [Serializable] classes. Line, SceneName, Expandable, MinMaxSlider, Required, SelfAssign and Preview work anywhere.
  • Scripts that use none of these attributes get Unity's normal inspector.
  • Can't be installed alongside NaughtyAttributes, since both replace the inspector. To switch, see the migration guide.
